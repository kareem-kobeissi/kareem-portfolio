# Kareem Kobeissi Portfolio

Personal portfolio for [Kareem Kobeissi](https://kareemm.com), a Full-Stack Developer specializing in web applications, REST APIs, database development, mobile applications, and business automation.

## Technology

- Next.js 14 and React 18
- Tailwind CSS and Sass
- GSAP and Framer Motion
- Nodemailer contact API

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm run start
```

The production deployment requires `GMAIL_USER` and `GMAIL_APP_PASSWORD` environment variables for the contact form.
